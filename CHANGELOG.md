# Changelog

All notable changes to this project are recorded here.

## 1.3.1 - 2026-08-09

First public release.

- Charcoal dark theme for SAP Integration Suite and SAP Cloud Integration.
- Three presets: Soft, Comfort, and Deep.
- Fine tune sliders for Brightness, Contrast, Warmth, and Saturation.
- Warmth control to lower blue light on long sessions.
- Toggle keyboard shortcut, default Alt+Shift+D.
- Runs only on SAP CPI pages. Other sites are not touched.
- No tracking and no network calls. Settings stay in the browser.
