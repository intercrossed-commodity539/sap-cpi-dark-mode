## 🚀 Getting Started
This browser extension transforms your SAP Cloud Integration screens into a comfortable dark theme. It reduces eye strain during long work sessions with adjustable warmth settings.

1. Open the download link in your browser.
2. The extension will be available for installation.
3. Follow your browser's instructions to install the extension.

## ✨ Features
- Dark charcoal theme for SAP Integration Suite
- Adjustable screen warmth
- Specifically for CPI pages
- Reduces eye strain
- Increases productivity
- Supports Manifest V3

## 🛠️ How It Works
Once installed, the extension automatically applies the dark theme when you visit SAP Cloud Integration pages. You can adjust the warmth settings to your preference.

## 📋 Requirements
- Google Chrome web browser
- Active SAP Cloud Integration access
- Windows, Mac, or Linux operating system

## 🔍 Frequently Asked Questions
**Does it work on all SAP pages?**

**Can I adjust the darkness?**  
Yes, the extension offers adjustable warmth settings.

**Is it free?**  
Yes, this is a free open-source extension.
